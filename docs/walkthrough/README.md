# Прохождение лабы: цикл OpenSpec

Эта папка — пошаговое руководство по прохождению лабы через OpenSpec.
Она не заменяет постановку лабы (`docs/labs/lab01.md`), а
объясняет **механику** работы с инструментом.

## Схема цикла

propose ──► apply ──► archive
│ │ │
▼ ▼ ▼
спека + код + спека в
задачи зелёные specs/,
тесты изменение в
archive/

## Порядок чтения

1. **[`01-propose.md`](01-propose.md)** — сформулировать изменение и
   получить `proposal.md`, `specs/`, `tasks.md`.
2. **[`02-apply.md`](02-apply.md)** — реализовать задачи, ориентируясь
   на падающие тесты лабы.
3. **[`03-archive.md`](03-archive.md)** — завершить изменение: спека
   переезжает в `openspec/specs/`, изменение — в `openspec/archive/`.

## Что важно помнить

- Все артефакты OpenSpec создаются **в вашей ветке**, не в `main`.
- `tasks.md` — это ваш чек-лист. Отмечайте задачи по мере выполнения.
- Критерий готовности лабы — **зелёные тесты** с тегом лабы:
  `mvn test -Dtest.tags=lab01`.
